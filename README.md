# 쓰담

쓰담 Windows 앱의 공식 다운로드와 릴리즈 노트를 제공하는 저장소입니다.

## 다운로드

[릴리즈 목록](https://github.com/afwaaak/ssudam-releases/releases)에서 버전별 설치 파일과 변경 사항을 확인하세요.

현재 이 저장소에는 배포 파일이 등록되어 있지 않습니다. 첫 릴리즈가 게시되면 다운로드할 수 있습니다.

## 업데이트

자동 업데이트를 지원하는 설치형 앱은 이 저장소의 정식 릴리즈를 통해 새 버전을 받도록 연결할 예정입니다.

## 저장소 안내

이 저장소에는 공개 배포 파일, 릴리즈 노트, 사용자 안내만 등록합니다.
앱 소스 코드는 별도의 비공개 저장소에서 관리합니다.

설치 파일에 포함된 오픈소스 구성 요소의 라이선스 및 고지는 앱과 함께 제공됩니다.
